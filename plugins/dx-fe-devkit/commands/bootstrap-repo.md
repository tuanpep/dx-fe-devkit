# Bootstrap repo bindings

1. Read `skills/fe-kit/references/bootstrap-repo.md`.
2. Copy templates from `templates/repo-bootstrap/` into the **target repository** under `.cursor/skills/`.
3. Fill paths, lint/test commands, and design-system mapping from the repo's `package.json` and folder layout.
4. Add root `AGENTS.md` pointer: `@fe-kit`.
