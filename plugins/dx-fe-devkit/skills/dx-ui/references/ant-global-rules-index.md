## Interaction principles

| Ant rule | Meaning (short) | Ant URL | Read here |
| -------- | ----------------- | ------- | --------- |
| Make it Direct | Shortest path; edit in context | [direct](https://ant.design/docs/spec/direct) | [overlays-decision-tree](overlays-decision-tree.md), [forms-validation-ux](forms-validation-ux.md) |
| Stay on the Page | Overlays/inlays/virtual pages vs hard navigation | [stay](https://ant.design/docs/spec/stay) | [layout-design](layout-design.md), [multi-step-flows](multi-step-flows.md), [feedback-states](feedback-states.md) |

| Use Transition | Motion explains change; preserve context | [transition](https://ant.design/docs/spec/transition) | [motion-feedback](motion-feedback.md) |
