# Kit catalog

**Prefix:** `fe-*` = engineering · `dx-*` = design language · **Hub:** `@fe-kit`

| Skill | Scope |
| ----- | ----- |
| `fe-kit` | Routing, bindings, bootstrap, verify |
| `fe-architecture` | Modules, slices, layers, public API, RQ, strangler, audits |
| `dx-ui` | Admin UX patterns (Ant spec SSOT) |
| `dx-ui-review` | UX gap reports & refactor plans |
| `fe-naming` | Identifiers, paths, hooks, tests, query keys, i18n keys |
| `fe-forms` | RHF/Zod, create/edit, server errors, wizards (UX from `dx-ui`) |
| `fe-testing` | Trophy levels, RTL, MSW, Query, forms, a11y, Playwright scope |
| `fe-i18n` | Keys, ICU/RTL, formatters, CI verify (copy from `dx-ui`) |
| `fe-security` | XSS, auth/BFF, CSRF, redirects, uploads, CSP, embeds |
| `fe-performance` | CWV (LCP/INP/CLS), budgets, SPA route timings, enterprise tables |
| `fe-mantine` | Mantine MCP & version discipline |
| `fe-git-workflow` | Branching model, commits, PRs, releases (binding) |

**Out of scope:** marketing sites, non-React stacks, full DevOps/CDN.

**Add-ons:** [external-catalog.md](external-catalog.md) (react-doctor, Context7, DevTools MCP).

Repo facts: one [repo-binding-template.md](repo-binding-template.md) (or split files listed in [resolve-binding.md](resolve-binding.md)).
