## Required fields

| Section | Content |
| ------- | ------- |
| **Layout** | Module, feature, layer, test file path patterns |
| **TypeScript** | camelCase / PascalCase exceptions |
| **Files** | Page vs hook vs util naming; test suffix (`*.spec.ts(x)` vs `*.test.*`) |
| **API fields** | Mirror OpenAPI / shared types — no FE-only renames |
| **i18n** | Key namespace convention; verify command if any |
| **Verification** | Lint/test commands for naming-related checks |
